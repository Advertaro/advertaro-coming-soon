## Edit

The edit uses cropped shots, 80% playback speed, a warm orange grade, and navy shadows.
The portrait fabric shot rotates 90° to fill the landscape frame at its native resolution.
The final second blends into the opening source motion. There is no audio track.
The footage contains no added text, camera UI, timecode, logo, or music.

The poster and the three preview frames come from this edit. They use the same source licences.
Source file hashes, the build script, and verification evidence are in `docs/creative/hero-reel/`.
Use the finished edit as part of the Advertaro site. The source licences still apply to the source footage.
